# OpenRice 0.8.9

OpenRice 0.8.9 is the first OpenRice-owned desktop release candidate. It packages
the independent OpenRice brand and update channel so end users can install a DMG
instead of cloning and compiling the repository.

## Included

- OpenRice application name, icon, bundle identifier, executable, and GitHub
  update channel.
- Favorite Skills menu from MET-30.
- Restricted-storage language fallback from MET-29/MET-31.
- Codex runtime detection and the OpenRice development framework documents.
- GitHub Actions release-candidate builds for one selected platform.
- Strict version consistency checks before packaging.
- Correct OpenRice executable verification during macOS signing.

## Installation

Download the installer matching the Mac processor from the OpenRice GitHub
Release page, open the DMG, and drag `openrice.app` into Applications.

The manually dispatched unsigned release candidate is for internal acceptance
only and may show a macOS security warning. The public release must be signed
with an Apple Developer ID certificate, notarized, and stapled before its `v0.8.9`
tag is pushed.

## Compatibility

OpenRice keeps the existing `.openloomi` data paths and plugin protocol IDs for
migration compatibility. Installing 0.8.9 must not delete or silently relocate
existing local data.
